# 8085 Assembly Language Programs

A collection of 8085 Assembly Language Programs (ALPs) I Used for 12th Boards.

## Topics

- Arithmetic Operations
- 1's and 2's Complement
- Bit Manipulation
- BCD Operations
- Conditional Operations
- Memory Operations
- Block Operations
- Searching and Sorting
- Miscellaneous Programs

## Tools

- Intel 8085
- Assembly Language
- Retro Assembler
